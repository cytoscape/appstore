Submitting a Web App Bundle

Web apps run in the user's browser inside Cytoscape Web. Submit a ZIP file containing your app's production build. Submission via GitHub repository is not supported yet.

The Cytoscape Web App API is still in beta and may change. Please contact us when submitting an app.

Prepare your bundle

To learn how to build a web app, explore the Cytoscape Web app examples.

  1. Build your app using your project's production build command, such as npm run build.
  2. Check that the build includes remoteEntry.js, cy-manifest.json, and all JavaScript chunks and assets needed by your app. If the manifest is missing, rebuild with a recent version of create-cytoscape-app or add it to your build output.
  3. ZIP the contents of your build output folder (usually dist). Keep remoteEntry.js and cy-manifest.json at the ZIP root, with chunks and assets in their original relative paths. A single enclosing build folder, such as dist/, is also supported. Include only one remoteEntry.js.
  4. Use a .zip filename and keep the bundle at or below 50 MB. Do not include source files or node_modules.

App identity and version

The Store reads the app's identity, display name, and version from cy-manifest.json. It must be valid JSON containing id, name, and version, for example: 

{
  "id": "myApp",
  "name": "My App",
  "version": "1.0.0"
}
  • id must match your bundle's Module Federation container name and CyApp.id, including capitalization.
  • name is displayed on the app page with its original capitalization. The Store derives a lowercase identifier from it for URLs, removing spaces, punctuation, and underscores.
  • version identifies this release. Use a new version number for each new release and keep the display name consistent when submitting updates to an existing app.

Submit and confirm

  1. Sign in and open the Submit Web App form.
  2. Upload your ZIP file and click Submit. The form requires only the bundle; the app name and version come from the manifest, and the author comes from your account.
  3. Review the app name, version, and author on the confirmation page. Accept the submission if they are correct, or cancel and upload a corrected bundle.

New apps require manual review before publication. If you are an editor of an existing web app, accepting the submission publishes the release to that app directly.

Troubleshooting

  • Make sure the file is a valid ZIP and does not exceed 50 MB.
  • Include remoteEntry.js and all of its required assets.
  • Include a valid cy-manifest.json with all three required fields: id, name, and version.
  • Avoid absolute paths and parent directory paths such as ../ inside the ZIP.
  • If the app fails to load in Cytoscape Web, check that the manifest ID matches the bundle's app ID and Module Federation container name.
